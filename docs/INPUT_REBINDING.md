# 조작키

설정 → **조작키 변경…**에서 이동·달리기·앉기·점프·F 상호작용·일시정지를 변경한다. 조사와 도구는 상호작용 하나로 실행한다. Tab은 휴대 단말용 고정 키다. Android는 터치와 키보드를 함께 사용할 수 있다.

편집 중 이동·점프·상호작용·시선 조작을 잠근다. 같은 키 중복·키 조합·repeat·release 입력을 거부하며 저장·취소·기본값 복원을 지원한다. 창을 닫은 뒤 누르던 키를 놓기 전에는 플레이 입력을 재개하지 않는다. PC에서 앱 포커스가 돌아오면 클릭 후 조작을 재개하고, 모바일은 터치 조작을 바로 재개한다.

`user://input_bindings.json`에 물리 키를 저장한다. 손상·누락·잘못된 형식은 기본값으로 복구하며 손상 원본을 자동 덮어쓰지 않는다. 명시적 저장은 임시 파일 쓰기·flush·rename 성공 후 적용한다. 기존 프로필의 비활성 `inspect` 필드는 호환성을 위해 보존하지만 E 조사 기능은 노출하지 않는다. 조사 진행·controls.cfg·업데이트 설정은 변경하지 않는다.

`godot/scripts/input_bindings.gd`는 정의·검증·파일 저장, `input_rebinding.gd`는 편집 UI를 담당한다. `python scripts/prototype-test.py --suite scene`은 실제 버튼·편집 창·이동·점프·저장·복원과 반응형 UI를 자산 없는 장면에서 검사한다. 플랫폼 차이는 수동 EXE·APK 검증에서 확인한다.
