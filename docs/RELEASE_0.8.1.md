# 0.8.1 통합 점검

| 점검 항목 | main 기존 상태 | 0.8.1 반영 |
| --- | --- | --- |
| 조사 게임 | 1~4일차 핵심 사건, 5~7일차 기본 진행 | 유지 |
| 사무실·이동·문·충돌 | godot-port의 검증된 맵 | 유지 |
| 조작·화면·모바일 | F 상호작용, 목표 표시, 비율 조정, 터치, 로딩 화면 | 유지 |
| 조사 UI·명령·대화 | 직접 조사 지시 후 UI 노출, help 후 명령, 대화 시선 유지 | 유지 |
| 지원·업데이트 | 로컬 진단, 저장 검사, 동의 후 설치·건강 확인·실패 복구 | 유지 |
| 코드·검증 | 웹·구 학습 게임과 중복 검증 포함 | 현재 조사 게임으로 정리, 영역별 빠른 검사 |
| 설정 화면 | 단말 안 설정·별도 키 변경창 | 일반·화면·소리·조작 카테고리, 키 변경·감도·시야각 저장 |
| 배포 | 기존 수동 배포 | main Windows 정식, beta Windows·Android 자동 검사·릴리스 |

미병합 브랜치 점검에서 `feature/settings-ui`의 설정 화면 1커밋을 확인해 통합했습니다. `godot-port`에는 추가 미병합 커밋이 없습니다. 기존 사무실 자산·장비 배치·조사 저장·Android 패키지 ID와 beta 서명은 유지합니다.

아직 미구현인 항목은 메인 메뉴, NPC 이동 AI·표정·립싱크, 5~6일차 상세 경위 대조·최종 행위자 보고, T-19 통제·반출 결과·7일차 정식 결말입니다. 실제 휴대폰 장시간 성능·사용성 검토와 추가 모바일 자산 최적화도 후속 작업입니다. 이 항목들을 이번 버전에서 구현 완료로 표시하지 않습니다.

검사 결과와 실제 배포 파일은 0.8.1 릴리스 및 해당 Actions 실행에 기록합니다. Codex가 점검·통합했습니다.
