# 다음 작업

저장 보호·시작 복구·단일 실행·진행 이동·미션 구조 개선은 v0.3.0에 구현했습니다.

선택형 3D 실습실은 v0.4.0, Chrome 렌더링·실내·이동 개선은 v0.5.x, 기존 미션의 현장 조사와 장비 재확인은 v0.6.0에 구현했습니다. v0.6.1은 장비별 E/F, 구역·방향과 재확인 이유 안내를 다듬었습니다. 기본 화면은 2D로 유지합니다.

1. 공식 환경인 Windows 10/11 최신 Chrome에서 내장·외장 GPU 장시간 실행 확인.
2. 입문자 3–5명에게 현장 조사→설정→재확인 흐름을 시연하고 막힌 위치와 학습 결과 기록.
3. 200% 확대·키보드·스크린리더는 기존 2D 도구에서 점검.
4. 결과를 반영해 장비 안내와 기록을 조정한 뒤, 기존 공간을 활용하는 SOC 사건 분석 미션 검토. 모바일·다른 브라우저 지원은 확대하지 않음.
