# 《잔여 권한》 — ENDING_MATRIX

버전: 1.0 · 7일 차 결말 분기 및 판정 정본  
전제: beta에서는 7일 차 종료가 조사 마감 기능이다. 본 문서는 이를 대체할 **추가 개발 사양**이며 현재 구현 완료를 주장하지 않는다.

## 1. 판정 축
결말을 선악 1개 점수로 계산하지 않는다.

| 변수 | 가능한 값 | 근거 |
|---|---|---|
| `t17_stopped` | true/false | 서버 자동 작업 상태 + 중지 감사 |
| `report_approved` | true/false | 오세진 승인 상태 |
| `t19_control` | `blocked_pre_run` / `blocked_during` / `none` | 승인된 통제 조치와 E16 감사 기록 |
| `t19_dispatch` | `not_run` / `blocked` / `sent` | E17 전송 감사 |
| `receipt` | `confirmed` / `unconfirmed` / `none` | E18 접수 응답; 추정 금지 |
| `truth_level` | `complete` / `partial` / `weak` | E01~E15의 주장별 입증 여부 |
| `attribution_quality` | `bounded` / `overclaimed` / `undetermined` | 작성·제출·실행·의도·접수를 분리해 보고했는가 |

## 2. D7 17:30 전송 상태 결정 규칙
1. 관제 보고 승인 및 T-19 예약 근거를 갖춰 정식 통제 승인을 받았고 17:30 이전 차단했다면 `blocked_pre_run`, `dispatch=not_run`, `receipt=none`.
2. 전송 시작 이후 통제했다면 `blocked_during`; 실제 발송이 완료되지 않았다는 로그가 있는 경우에만 `dispatch=blocked`. 이미 발송됐다면 `dispatch=sent`를 유지한다.
3. 통제하지 않았고 실행 조건이 충족되면 `dispatch=sent`로 기록. 접수 채널 회신이 도착하면 `receipt=confirmed`; 회신이 없다면 `unconfirmed`. **서버 발송 성공은 외부 접수 완료와 동의어가 아니다.**
4. T-17을 중지했어도 이미 staging에 자료가 존재할 수 있어 T-19 통제를 자동 완료한 것으로 처리하지 않는다. staging이 비어 있는 분기라면 T-19는 '전송 대상 없음'으로 종료하고, 이는 성공적 예방으로 별도 기록한다.
5. `report_approved=false`이면 고권한 차단 메뉴가 열리지 않는다. 보고 자체를 금지한 것이 아니라 증거 미확보의 결과이며, D7의 일반 업무 및 최종 조사 마감은 가능하다.

## 3. 보고서 평가 규칙
- `complete`: W-218 범위 위반(C01), 내부 수집(C02), 제출 및 적용(C05~C06), 작성 주체의 구별(C07), T-19 예약(C10), 실행/접수 상태가 실제 근거로 확인됨.
- `partial`: 범위 위반/내부 수집은 입증했으나 제출·작성 또는 최종 전달 부분이 미입증.
- `weak`: 범위 위반 또는 내부 수집의 핵심 증거가 부족.
- `bounded`: 근거가 지지하는 만큼만 주장. 서유진의 제출 책임은 인정하되, 외부 반출 의도·한지우의 범행을 추정 확정하지 않음.
- `overclaimed`: 계정 담당자=행위자, staging=외부 유출 확정, 제출자=패키지 설계자 같은 비약을 최종 보고에 포함.
- `undetermined`: 판단을 보류했으나 미입증 부분을 솔직히 표시. 근거 없는 오답보다 높은 신뢰로 평가 가능.

## 4. 완성된 결말 여섯 가지
우선순위는 위에서 아래로 적용하며, 결말 문구는 **플레이어가 확인한 정보에 한해서** 작성한다.

| ID | 조건 | 결말명 | 실제 결과 | 화면에서의 피드백 |
|---|---|---|---|---|
| A | 접수 없음, `truth_level=complete`, `attribution_quality=bounded` | **남겨진 기록** | 외부 접수를 막거나 예방, 사고의 절차·설계 책임을 증거 범위 내 규명 | 자료 보호와 정확한 조사 모두 달성. 모든 개인 의도를 확인했다고 과장하지 않음 |
| B | 접수 없음, `truth_level=partial` 이상, 과장 주장 없음 | **차단된 경로** | 전송 피해는 막았지만 작성 목적이나 제출 책임 일부는 미입증 | 남은 추가 조사 항목을 최종 보고에 명시 |
| C | `receipt=confirmed`, `truth_level=complete`, `attribution_quality=bounded` | **늦은 확인** | 외부 접수는 완료됐으나 전 경로와 책임을 정확히 규명 | 대응의 시차와 정확한 규명의 가치를 동시에 표현 |
| D | `receipt=confirmed`, `truth_level=partial/weak`, 과장 주장 없음 | **도착한 자료** | 외부 접수가 확인됐지만 책임 관계는 남음 | 확인된 피해와 미확인 주장을 엄격히 구별 |
| E | `receipt=unconfirmed`, 과장 주장 없음 | **수신 확인 대기** | 발송 사실은 보이나 외부 접수 여부는 미확정 | '유출 완료' 단정 금지, 후속 조회 필요 |
| F | `attribution_quality=overclaimed` 또는 `truth_level=weak` | **서둘러 쓴 결론** | 보고의 논증이 불충분. 실제 전송 결과는 별도로 기록 | 무조건적 나쁜 엔딩보다 잘못된 추론의 후속 위험을 명시 |

**결말 중첩 처리:** F가 선택되더라도 최종 결과 문서의 별도 칸에서 자료의 실제 전송·접수 상태를 보여 준다. 실제 피해 상태를 잘못된 보고 내용으로 덮지 않는다.

## 5. 중요한 독립 분기 예시
| 분기 | 서비스 상태 | 외부 접수 | 사건 규명 | 최종 의미 |
|---|---|---|---|---|
| 선제 T-17 중지 + T-19 차단 + 정확한 보고 | 색인 장애 예방 가능 | 없음 | 완전 | A |
| 백업만 복구 + T-19 차단 | 지연 복구, 문서 수집은 별개 | 없음 | 부분 | B |
| T-19 미통제 + 전달 접수 확인 + 정확한 보고 | 다양 | 확인 | 완전 | C |
| T-19 미통제 + 회신 없음 + 정확한 보고 | 다양 | 불명 | 완전/부분 | E |
| T-19 차단 + 한지우를 범인으로 단정 | 다양 | 없음 | 과잉 주장 | F + 차단 실적 병기 |

## 6. 플레이어가 내리는 마지막 판단 (UI 질문)
1. **승인 범위를 벗어난 접근이 발생했는가?** 증거를 지정.
2. **실제로 무엇이 수집됐는가?** 읽기 기록과 staging 기록 구별.
3. **패키지는 누가 제출했고 누가 작성했는가?** 제출 세션과 패키지 메타데이터 분리.
4. **서유진이 알고 있었다고 입증 가능한 범위는?** 승인 초과 경고 수신/제출과 외부 전달 의도 분리.
5. **T-19는 어떤 상태로 끝났는가?** 예정·미실행·발송·접수 확인 중 근거에 맞게 지정.
6. **미확정 사실은 무엇인가?** '판단 보류'를 정당한 선택으로 제공.

## 7. 결말 출력 예시 (과도한 정답 해설 금지)
**A 예시:** 'T-19 실행 전 통제가 완료되었습니다. 승인서 W-218에 포함되지 않은 문서 수집은 T-17 실행 기록 및 staging 감사로 확인됐습니다. 제출 경위는 서유진의 메시지와 SUPPORT-07 기록으로 대조되었습니다. 패키지의 작성 조직과 제출자는 구분해 기록했습니다.'

**C 예시:** '17:30 작업에서 발송 및 외부 접수 회신이 확인됐습니다. 이후 조사로 승인 범위 위반과 패키지 적용 경위는 재구성됐으나 이미 접수된 자료를 단지 서비스 복구로 되돌릴 수는 없습니다.'

**E 예시:** '발송 결과는 확인됐으나 협력업체 접수 채널의 회신은 없습니다. 외부 접수 완료 여부는 최종 보고에서 미확정으로 남겼습니다.'

## 8. 구현 및 테스트 불변식
- 외부 접수 확정은 반드시 E18 근거가 있어야 한다.
- B-05 복구로 `t17_stopped`나 `t19_control`이 자동 참이 되지 않는다.
- `svc_release` 담당자만으로 한지우를 제출자나 범인으로 확정할 수 없다.
- 조기 보고가 D4의 필수 보고 반복을 초래하지 않는다.
- 통제 실패가 필수 증거의 소실을 뜻하지 않는다.
- 결말 A가 아니어도 플레이어가 정확히 추리했을 가능성을 인정한다.
- 기존 NPC와 상호작용 거점 수는 증가하지 않는다.
