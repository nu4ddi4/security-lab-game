# SecurityLab-beta-0.4.0 검증 기록

2026-10-07 · Godot 4.7.2 stable · Windows x64 / Android 15 에뮬레이터.

상호작용·화면 비율·터치·로딩 개선을 `feature/beta-ux-mobile`에서 개발한 뒤 최신 beta의 키 재설정 기능과 통합했다. 빌드 검사 시간 제한 수정은 `fix/beta-rendered-check-timeout`에서 반영했다. main과 원본 기능 브랜치는 유지한다.

## 검증한 소스

- 배포 파일 소스: `139af5813237c21a76ce26dfcbae92a41d74e09f` — [Windows·Android 패키지 CI](https://github.com/nu4ddi4/security-lab-game/actions/runs/37600894731), 두 플랫폼 모두 성공.
- 같은 소스의 [전체 Test CI](https://github.com/nu4ddi4/security-lab-game/actions/runs/37600895218)는 성공했다. 기존 Native Windows 빌드와 회귀 검사를 포함한다.
- 릴리즈 문서·게시 워크플로만 후속 변경하며 배포 파일은 검증한 CI 결과를 그대로 사용한다. 게시 시 소스 차이·artifact SHA·체크섬·제품·채널을 검증한다.

## 통과한 검사

사건·저장 시나리오 462개/8개 시나리오, 베타 서비스 23개, Native 규칙 452개·업데이트 90개·진단 검사, 키 바인딩 규칙 113개와 실제 편집 창·입력 잠금·저장 검사를 재사용한다. 장비 가장자리·거리·인접 대상·벽 차단, F 단일 상호작용, E 제거, 카메라 시선 유지, 도움말 요청 전 명령 숨김, 조사 지시 전 UI 숨김도 기존 smoke/unit에서 확인했다.

1280×720·1024×768·960×540·540×960의 열린 패널과 터치 버튼 경계를 검사하고, Windows EXE 및 Android 앱 화면을 기록한다. EXE 단독 실행·저장·재실행, Inno 설치·실패 복구·업데이트 동의 흐름과 Android 터치 기본값·키보드 감지·백그라운드 저장·같은 서명 덮어 설치·재실행을 확인한다.

자산은 보호된 기능 인터페이스 101개, 정확한 지오메트리 98개, 키보드·의자 배치 26쌍을 유지한다. CI 정책 검사 32개가 통과했다. ignore는 생성/비공개 경로 24개 제외·필수 경로 14개 유지·추적 중 파일 제외 없음으로 확인했다. 새 커밋 작성자/커미터는 `codex-nu4ddi4`와 GitHub 비공개 이메일을 사용한다.

Windows EXE 단독 실행 2회, 실제 렌더링 UI·입력, 키 재설정 26개, Native/beta Inno 설치·복구 47/54개, 동의 흐름 18개가 통과했다. Android는 설치·렌더링·터치·키보드·저장 보존·재실행이 모두 통과했다. Windows 화면 검사만 90초에서 180초로 조정했으며 게임 동작과 다른 검사 기준은 유지했다.

로딩 원인·측정의 한계와 후속 최적화는 [모바일 개선 기록](BETA_UX_MOBILE_PLAN.md)에 남겼다. 실제 Windows PC·Android 휴대폰의 장시간 플레이, 발열·메모리·최초 실행 성능과 화면 키보드·노치·가로/세로 전환은 안정화 단계에서 추가 확인한다. 이번 배포는 main 병합을 포함하지 않는다.

# SecurityLab-beta-0.3.0 검증 기록

2026-10-07 · Godot 4.7.2 stable · Windows x64 / Android 15 에뮬레이터.

beta는 main `41d44b0`에서 생성하고 조사 프로토타입, godot-port, Native updater 및 diagnostics 브랜치를 병합했다. 사건·저장·대화·터미널·혼합 입력은 프로토타입을 유지하고 사무실 맵·문·충돌·도시 외관은 검증한 godot-port를 사용한다. 원본 브랜치와 main은 유지한다.

## 검증한 소스

- Windows·Android 배포 파일: `12414875df2afa7ca7f0d8a030d30b8870776c23` — [베타 패키지 CI](https://github.com/nu4ddi4/security-lab-game/actions/runs/37588539463), 두 플랫폼 모두 성공.
- 기존 Native 회귀 및 패키지: `509b42a794ae04c23a091bc5af0736be371cc3bf` — [전체 Test CI](https://github.com/nu4ddi4/security-lab-game/actions/runs/37588965893), 필수 test 성공.
- 두 SHA 사이 변경은 Native 전용 빌드 스크립트의 Windows 줄바꿈 처리뿐이다. 베타 게임·설치 파일·빌드 입력은 동일하다. 릴리즈는 검증한 베타 파일을 재사용하며 source diff·artifact SHA·체크섬·product/channel 검증을 거친다.

## 안정화 후 main 반영 조건

- 실제 Windows PC·Android 기기에서 사용성, 메모리·발열·성능과 장시간 플레이를 확인한다.
- 기존 proto-0.2.0 진행 파일로 여러 날짜의 사건 진행·내보내기/가져오기를 확인한다. 코드의 저장 포맷·경로·논리 ID는 변경하지 않았다.
- 업데이트 서버 연결 실패 후 설정 버튼 재시도 UX를 보완한다. 실패 시 플레이와 저장은 계속 가능하며 설치는 수행하지 않는다.
- 진행 차단·저장 손실·사용자 동의 없는 설치 문제가 없고 안정화가 완료되면 beta → main 병합을 진행한다. 이번 릴리즈는 main 병합을 포함하지 않는다.
