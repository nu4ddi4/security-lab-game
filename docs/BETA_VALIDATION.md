2026-10-07 · Godot 4.7.2 stable · Windows x64 / Android 15 에뮬레이터.

beta는 main `41d44b0`에서 생성하고 조사 프로토타입, godot-port, Native updater 및 diagnostics 브랜치를 병합했다. 사건·저장·대화·터미널·혼합 입력은 프로토타입을 유지하고 사무실 맵·문·충돌·도시 외관은 검증한 godot-port를 사용한다. 원본 브랜치와 main은 유지한다.

## 안정화 후 main 반영 조건

- 실제 Windows PC·Android 기기에서 사용성, 메모리·발열·성능과 장시간 플레이를 확인한다.
- 기존 proto-0.2.0 진행 파일로 여러 날짜의 사건 진행·내보내기/가져오기를 확인한다. 코드의 저장 포맷·경로·논리 ID는 변경하지 않았다.
- 업데이트 서버 연결 실패 후 설정 버튼 재시도 UX를 보완한다. 실패 시 플레이와 저장은 계속 가능하며 설치는 수행하지 않는다.
- 진행 차단·저장 손실·사용자 동의 없는 설치 문제가 없고 안정화가 완료되면 beta → main 병합을 진행한다. 이번 릴리즈는 main 병합을 포함하지 않는다.
